# test_repo

Simple static pages used for testing.

## Quick code review notes

- `index.html` now uses valid semantic structure (`<h1>` and `<p>` are siblings instead of nesting a paragraph inside a heading).
- Added clearer document title for easier browser-tab identification while testing.

## Manual test checklist

1. Open `index.html` in a browser.
2. Verify the heading renders as `Hello bla`.
3. Verify the paragraph renders as `Content` below the heading.
4. Open `feature_1.html` and confirm the page loads without console errors.
